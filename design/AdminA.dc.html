Roles (managed in Keycloak)

AUDIT_WRITER sends records. Cannot read them.
MINISTRY_AUDITOR reads everything and reviews.
PRIVACY_OFFICER reads everything, settles disagreements.
FACILITY_AUDITOR reads only its own facility.
AUDIT_ADMIN manages the console.
A person cannot both send and read. Keycloak refuses that mix.

Users

Planned · next release
Invite a person, set their role, disable them and send a password reset, without opening Keycloak. Done through Keycloak's Admin API using a service account limited to this realm. Every change is recorded in the console activity log. Realm settings, clients and sign-in policy stay in Keycloak.
The service account can create users, so its secret is stored with the same care as a database password.
